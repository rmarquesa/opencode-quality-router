This is a reference artifact for the eval suite; it is not installed as a personal skill.

Use OpenCode's native session API and configured authentication. Do not copy or print credentials. Use empty temporary directories and fresh evaluation sessions; deny tools and do not touch the user's active sessions. Keep exact case truth in the collocated Task.md and verifier, not in this file.

Model choice and provider recovery are different from code quality. Treat catalog capabilities as technical metadata, costs as reference rates, and unknown quota/ability as unknown. Distinguish each provider/model and each domain/complexity cell. Provider/timeout/output-budget failures are not capability failures. One deterministic smoke trial is limited evidence. Use source tests to prove routing mechanics and real native responses only for the exact smoke case they passed.

Relevant paths: src/index.mjs (task tickets and decisions), src/matrix.mjs (evidence cells), src/recovery.mjs (bounded same-session recovery), test/native-integration.mjs (synthetic routing checks), evals/model-routing/cases.mjs (case instructions and independent verifiers).
